## §1 项目说明（Project write-up）

### The challenge

农夫山泉卖的不是水，是**水源地**。它八年来的水广告都在**山的外面**拍：
长白山的雪、鹿、森林、四季。观众记住了「那里很干净」，但没有记住**为什么这瓶水只能来自那里**。

真正把长白雪和其他瓶装水分开的，是一个谁也拍不到的事实：
水在火山玄武岩里**走三十到六十年**才出来。这三十年发生在岩缝里，任何摄影机都进不去——
所以它从来没有被拍过，也就从来没有变成过一句广告语。

Spec 广告的题就是：**把这段不可能拍到的路，拍成一条 30 秒的片子。**

### The creative and technical approach

**一句话主张：你喝到的，是三十年前的雪。**

片子是一次**连续下坠**，七镜全部向下运镜，剪辑点只是加速度：

雪落在玄武岩上化成水 → 顺岩缝进山 → 在岩层里走三十年 → 从泉眼涌出 → 进到瓶子里。

文案只出现四张卡，全部是品牌自己说过的话（西坡 / 距天池六十公里 / 三十到六十年 / 恒温七度），
最后落在主张上，末屏才是产品、口号与 AI 标注。

**技术上，这是一条可复现的管线，不是一次抽卡：**

| 层 | 做法 |
| --- | --- |
| 图版 | 六张生成式图像 → 去工具水印 → 裁 16:9 → 统一影调 → 放大到 2400×1350 |
| 时间 | 一个 30.000 秒的时间轴；叠化让后一镜提前 0.25–0.40 秒进来 |
| 运镜 | 每镜一条取窗路径（缩放 + 中心位移 + 缓动），全部向下 |
| 叠加 | 雪、雾、光晕、水线、水花、颗粒，全部由代码逐帧算，无外部素材 |
| 调色 | 一条色温曲线贯穿全片：冷 → 更冷 → 岩层里暖起来 → 泉眼最亮 → 末屏回到中性 |
| 声音 | numpy 合成：风、水、低频下潜、冰裂、脉冲、钟；卷积混响用噪声 IR；两遍 loudnorm 到 −16 LUFS |
| 断言 | 68 条：容器、响度、安全区、字幕时序、末屏三件、无脸、无水印、同帧两次渲染逐字节一致 |

**为什么这条路对**：本片要的是**同一个空间的连续性**，逐镜生成的视频模型保不住同一条岩缝；
而一条能一条命令重建的管线，正好对上 AARON 把工作流本身当作品的那套价值观。

### The results

- 成片 30.000 秒 / 1920×1080 / 24 fps / H.264 + AAC / −16 LUFS / 41.7 MB
- 68 条断言全绿（`python scripts/verify.py`）
- 全新 clone 只照 README 跑，可从零重建（记录在 `proof/clone-verify.log`）
- 一次连续下坠，五个语义层次（山外 / 进山 / 时间里 / 出泉 / 产品）由**色温**而非剪辑区分
