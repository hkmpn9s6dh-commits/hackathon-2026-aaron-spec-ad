# 02 创作

## 洞察

农夫山泉八年来的水广告都在**山的外面**拍：雪、鹿、森林、四季。
观众记住了「那里很干净」，但没有记住**为什么这瓶水只能来自那里**。

把长白雪和所有其它瓶装水分开的，是一个谁也拍不到的事实：
水在火山玄武岩里**走三十到六十年**才出来。这段路在岩缝里，任何摄影机都进不去——
所以它从来没有被拍过，也就从来没有变成过一句广告语。

## 主张

> **你喝到的，是三十年前的雪。**

它同时是三件事：

1. **产品的物理事实**（30–60 年深层溶滤）；
2. **品牌的一贯说法**（大自然的搬运工——搬的是时间，不是水）；
3. **一句只能属于这个品牌的话**：换任何一个别的瓶装水都不成立。

## 形式：一次连续下坠

七镜，全部向下运镜。剪辑点只是加速度，不是换场景。

| 段落 | 观众在哪 | 情绪 |
| --- | --- | --- |
| S01–S02 | 山外：雪坡 → 一片雪落在石头上化开 | 明亮、干净 |
| S03 | 进山：岩缝、玄武岩柱、唯一一处天光 | 收窄、变暗 |
| S04 | 时间里：岩层内部，水在看不见的裂隙里走 | 最静、最慢 |
| S05 | 出泉：水从岩壁涌出来 | 释放 |
| S06–S07 | 上桌：瓶子、主张、品牌 | 回到人间 |

**色温是这条片子的时间轴**：冷 → 更冷 → 岩层里暖起来 → 泉眼最亮 → 末屏回到中性。
观众不会读字幕，但会读颜色。

## 文案

只有四张事实卡 + 一张主张卡 + 末屏。全部短句，全部有出处（`docs/04-SOURCES.md`）。

删掉的东西，以及为什么：

| 删掉的 | 为什么 |
| --- | --- |
| 「地下六十米」 | 60 公里是**距天池的距离**，不是深度。宁可不说，不能编。 |
| 一句品牌口号的改写 | 口号是品牌的原话，改一个字就不是它了 |
| 配音 | 这条片子的语气是「让画面说」；加一条人声会把它变成说明书 |
| 结尾的产品旋转 | 那是电商详情页的语言，不是广告的 |
