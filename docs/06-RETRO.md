# 06 复盘

## 做对了的

1. **主张先于画面**。先有「你喝到的，是三十年前的雪」，再去找能承载它的七个镜头。
   中间砍掉的三个方案（雪山四季混剪、瓶子里的雪、水源地航拍）都是「先有画面再找话」。
2. **色温当时间轴**。一条 `GRADE` 曲线把七段不同的图版缝成一次下坠；
   观众读到的是「越走越深、越走越暖」，不需要字幕解释。
3. **断言写在渲染器之前**。第一次跑挂 7 条（时间轴、真峰、C5 时长、末屏标注、
   两处肤色误判、水印残留），每一条都是真问题，改完片子确实更好。
4. **单一事实源 + 反向生成分镜表**。改时长忘了改文档这类错，在 `verify.sh` 里是红的。

## 做砸了 / 还没解决的

1. **运镜是 2.5D 的**。贴得再近也骗不过一个盯着岩壁看的人：
   岩缝那一镜的「往下走」是取窗在移，不是摄影机在动。要真运动，得用文生视频或 3D 场景——
   本机没有出片通道（父单 11-03 已定不批），这是这一轮最硬的限制。
2. **产品镜是静态图版**。瓶身没有真实的旋转与折射，靠 bloom 与暗角遮。
   下一题如果还是产品，第一步应该是「让产品真的动起来」。
3. **没有配音**。这是选择，也是能力边界：本地没有可用的中文配音通道，
   而一段机器味的中文旁白会毁掉整支片子。
4. **闸 D 的盲排没有跑满**。五件真实广告的片子拿不到（只能用记忆与公开描述），
   所以「混排盲排」这一条只做到「主张复述」这一半。见 `proof/gate-d/`。
5. **图版是 1536×1024 放大到 2400×1350 的**。1.56 倍上采样，
   近看是软的；靠颗粒与浅景深遮过去了，但这不是真清晰。

## 下一题要改的三件事

| 改什么 | 怎么改 |
| --- | --- |
| 主体要有真运动 | 先看有没有可用的图生视频通道；没有就换题，不要再用 2.5D 假装 |

| 盲排要拿到素材 | 开赛前先把 5 件尺子的片子下下来；拿不到就改用「同题多版本」的内部盲排 |
