# 00 任务

## 这单是什么

**AME-1493 · 赛道 AE**。在 AME-1134（AI 比赛目录 v2）下自选的一场没打过、没人在打的比赛：

**AARON Awards 2027 · Creative Craft & Innovation · 08 Best Speculative Ad**

选它的唯一硬理由：这是 21 个类别里**唯一不要求真实品牌委托**的一类
（其余都硬性要求 commercially commissioned）。独立创作者只有这一扇门。

## 交付

一件 30 秒 spec 广告：**《三十年前的雪》**，农夫山泉 · 长白雪。

- 品牌事实：长白山西坡自涌冷泉、距天池六十公里内、约 30–60 年火山玄武岩深层溶滤、恒温约 7℃
- 主张：**你喝到的，是三十年前的雪。**
- 形式：一次不可能被拍到的连续下坠——雪花 → 岩缝 → 地下三十年 → 泉眼 → 瓶身

## 四闸

| 闸 | 计划 | 落点 |
| --- | --- | --- |
| A | 先写 30 秒演示脚本，再写可判定验收条件；风格预设、5 件尺子、1 个记忆点、末屏规格 | `SPEC.md`、`docs/07-UI.md` |
| B | 先写断言（时长/画幅/安全区/字幕时序/响度/末屏/色值/无脸/可复现），再实现 | `scripts/verify.py`（68 条） |
| C | 本机全绿 + 线上页 + 全新 clone 只照 README 跑 | `proof/` |
| D | 与 5 件真实广告混排盲排（≥2 位未参与评委，至少一位不同家族）+ 30 秒主张复述盲读 | `proof/gate-d/` |

## 不做什么

- 不用未经授权的实拍素材；六张图版全部生成式
- 不描品牌 logo 的标准字
- 不写没有出处的事实句
- 不做配音（本地没有可用的中文配音通道，机器腔会毁掉片子）

1. 看片
2. 2027-01-15 前在 aaronawards.com 注册并提交（免费）
3. 若要公开发布，确认品牌 spec 用法可接受（spec 广告是行业惯例，AARON 明说接受）
