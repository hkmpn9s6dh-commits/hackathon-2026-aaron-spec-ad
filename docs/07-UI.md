# 07-UI —— 视觉系统：风格、尺子、记忆点、末屏规格

> 闸 A 要求先定这四样，再动手。片子的「界面」就是它的字体、字幕位、末屏和调色。

## §1 风格预设（三选一）

| 预设 | 长什么样 | 用在哪 | 这次 |
| --- | --- | --- | --- |
| `glacier-doc` 冰川纪实 | 高亮度、蓝白、手持感、颗粒粗、无花字 | 品牌自己的水源纪录片 | 备选 |
| `deep-time` 深时间 | 低照度、青黑、单一光源、极慢推、稀薄字幕 | 这条片子的 12–18 秒 | — |
| `product-silence` 静物沉默 | 近乎无运镜、产品居中、光从背后过、字在左下 | 高端水、香水、腕表的常规收尾 | **选中** |

**选 `product-silence` 做收尾、`deep-time` 做中段**：一支 30 秒的片子要穿过两个世界（山外 / 山内），
如果全程一个调子，观众分不清「这是同一个下坠」还是「换了个场景」。
两套预设之间用**一条连续的色温曲线**缝合（见 `story.py` 的 `GRADE`）：
冷 → 更冷 → 岩层里暖起来 → 泉眼最亮 → 末屏回到中性。

参考的反例（不许出现）：
- 蓝到发紫的「科技感」水（廉价矿泉水的通用色）
- 慢动作水滴砸水面的老套（这条片子的水是**在石头里走**，不是砸出来的）
- 任何形式的品牌 logo 描摹

## §2 尺子（5 件真实广告 + 学哪一点）

| # | 尺子 | 学哪一点 | 不学哪一点 |
| --- | --- | --- | --- |
| R1 | 农夫山泉「长白雪」水源纪录片（品牌自己的） | 真实的雪、真实的脊线、真实的冷 | 它只拍山外，这正是本片要补的空 |
| R2 | Evian《Baby & Me》（BETC） | **一个不可能的画面撑起整支片**，不需要第二个点子 | 它的幽默感不属于这个品牌 |
| R3 | Guinness《Surfer》（AMV BBDO） | 慢镜头 + 一个隐喻，把「等待」拍成力量 | 它的男性荷尔蒙不属于这支水 |
| R4 | Chanel N°5 系列产品片 | 产品作为唯一主角时的**光与静**，字只占左下 | 它的距离感（本片要更亲近） |
| R5 | Coca-Cola《Masterpiece》 | 生成式影像如何**穿过**不同世界而不散架 | 它的拼贴感（本片要连续，不要拼贴） |

判据：把本片的任意一帧和这五件的一帧并排，**不能显得像学生作业**。
具体到可量：字幕字号不小于尺子的下限（1080p 下 46 px）、画面不留纯黑死区、
产品镜头必须有可见的高光与冷凝水。

## §3 一个记忆点

**那一滴从雪化开、穿过整座山的水**——全片只有一个主体，观众看完应该记住的是
「水在石头里走了三十年」这一件事，而不是七个好看的镜头。

可检验的说法：**看一遍，能不能用一句话复述主张**。这句话应该是
「你喝到的，是三十年前的雪」或它的等价说法。闸 D 的盲读就测这个。

## §4 末屏规格（主屏）

| 元素 | 规格 |
| --- | --- |
| 背景 | 瓶身图版压到 26% 亮度，底部再压一层渐变（字必须读得出） |
| 品牌行 | `农夫山泉 · 长白雪`，思源宋体 72 px，字距 0.06 em，白 97% |
| 分隔线 | 品牌行下 24 px，1 px，白 45%，长度 = 品牌行宽（上限 460 px） |
| 口号 | `我们不生产水，我们只是大自然的搬运工`，思源黑体 32 px，白 84% |
| AI 标注 | `水源地影像为 AI 生成示意`，思源黑体 20 px，白 60% |
| 位置 | 全部左对齐，x = 150 px；品牌基线 820 / 口号 898 / 标注 952 |
| 安全区 | 全部落在 5% 安全区内（断言 C 组） |

**字幕（片中四张卡）**：左下，x=150，基线 884；宋体 54–60 px，字距 0.05 em；
上方 64 px 处一条 2 px 短横线（只作视觉锚点）；带 4 px 偏移的黑色柔影 + 底部 30% 渐变，
保证压在亮水上仍然可读（S03、S06 都踩过这个坑）。
唯一例外：主张卡 `C5` 居中，基线 968，58 px。
